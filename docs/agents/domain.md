# Domain docs

Use the single-context layout for this repository.

## Before exploring

- Read the root `GLOSSARY.md`, if it exists.
- Read relevant decisions in `docs/adr/`, if any exist.
- If those files are absent, continue without suggesting that they be created preemptively.

## Layout

- `GLOSSARY.md` contains the shared domain vocabulary.
- `docs/adr/` contains repository-wide architecture decisions.
- Use glossary terms consistently. Surface conflicts with relevant ADRs instead of silently overriding them.
